# 岗位—任务网络中的再捆绑预测（Job-Task Rebundling）

## 研究问题

基于岗位—任务网络（job-task network），用三条再捆绑准则构建
可检验的「前因 → 若干年后 → 后果」预测链条：
某一时刻对象的结构特征，能否预测 T+1/2/3 年后的结局？

## 三条再捆绑准则

| 准则 | 理论来源 | 判定单元 | 前因 | 后果 |
|------|----------|----------|------|------|
| (a) 互补性再捆绑 | Milgrom & Roberts 1995; Kremer 1993 | 岗位任务集 | 高暴露可编码任务 + 语境嵌入任务共存 | 混合型新任务组合 |
| (b) 层级解绑 | Garicano 2000 | 任务团 | 同层级、可编码为主、功能凝聚 | 任务团分裂 |
| (c) 模仿性模板扩散 | DiMaggio & Powell 1983 | 企业 | 模板烙印残差（surf_sim 相对 struct_sim/xfirm_sim） | 新增岗位中模板采纳占比超中位 |

## 方法流程

1. **对象池构建**：T=2020 快照，每准则取前 2000 对象
   - g1 岗位（2000）、g2 任务团（1502）、g3 企业（307）
2. **后果标签**：T+1/2/3 年实测结局，按 job/seed/firm 对齐
3. **LLM 前因判定**：逐对象判 holds（0/1）+ 概率档位 p（0.05~0.9），
   判定协议见各准则协议文本
4. **条件概率汇总**：P(后果|holds=1) vs P(后果|holds=0)，
   对比基础率，计算提升比
