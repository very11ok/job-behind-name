# 职在名先：三守则 agent 在新材料岗位—任务网络上的首次回测

v1.0 · 2026-10-28 · 主设定 **T=2019 → 2020**；数据：中国新材料上市公司 2016–2026 招聘文本

---

## 0. 目标（一句话）

造一个遵守三条再捆绑守则的 agent：读 T 年岗位—任务二分网络快照，以
**(a) 互补性再捆绑 / (b) 层级解绑 / (c) 模仿性模板扩散** 为生成式准则，
**由 LLM 完成全部语义与相似度判定**（本体 agent + 子 agent 并行标注），
网络结构量、候选生成与评分回测由确定性算法完成，预测结果对照真实 T+1 网络与四个结构基线，
并强制通过"安慰剂对照"检验：语义增量必须来自 LLM 判定，而非任意语义特征。

## 2. 分析单元：三层，机制各归其层

| 层 | 角色 | 机制 | 判定事件 |
|---|---|---|---|
| **岗位 bundle**（任务集合） | 被再捆绑的对象 | (a) | 新 bundle 带"高×低暴露混合"任务集进场 |
| **企业 × 年** | 做决策的主体 | (b) | 企业内问题解决跨度收窄 / 拆岗事件 |
| **网络（场域）** | 扩散与检验的舞台 | (c) | 跨企业同构模板采纳 + 表面残差 |

理由：(a) 的互补性是**同一生产单元内**任务组合的性质；(b) 的知识层级长在**企业内部**，
网络总量看不出谁在拆岗；(c) 的模仿必须带**企业身份**才有意义（同企业复用不算扩散）。
逐对回测（§5）在网络层进行，因为预测者（外部分析者/agent）只能看到 T 年全网快照。

## 3. agent 的构成

**宪法**（`jtagent/prompts.py`，版本 v0.2）三段，均含知识截止纪律与"仅结构输出"约束：

1. **任务标注宪法**：把每条 O*NET 任务判成
   `codability(0–2)`、`judgment/coordination/accountability/embodied(0/1)`、
   `hierarchy(L0–L3，Garicano 知识层级)`、`module(17 类功能模块)`。
2. **任务对判定宪法**：给出每对的共捆绑概率 p、机制标签 `A/B/C/none` 与 ≤30 字依据。
3. **岗位生成宪法**：对高暴露岗位输出 T+1 的重构任务组合（约束只能从候选池取任务 id）。

**执行方式**：本会话的 LLM 即 agent 本体；规模化标注由 `workflow` 派子 agent 分波执行
（每批 48 条任务，并发≤6），少量子 agent 反复失败的批次由 agent 本体直接补标。
2019 年活跃任务 5,721 条 → **全部标注完成（120/120 批，QC 通过，100%）**，
覆盖候选对 **3,599,363** 对（全量）。

**属性源三档**：`lex`（英文词表，消融/安慰剂）、`llm`（LLM 标注）、`merge`（LLM 优先词表回填）。

## 4. 回测协议

- **候选池**：T 年任务投影网络中 2-hop 且未捆绑对。T=2019 全量 3,599,363 对。
- **标签**：`y=1` 该对在 T+1 年被任一活跃岗位捆绑；`y_new=1` 由 T+1 **新进场岗位**承担。
  T=2019 全量：46,485 正例，其中 **97% 由新进场 bundle 承担** → 预测对象 = 新岗位带来的新共捆绑。
- **基线族**：持续性（T-1 曾捆绑）、优先连接、共邻、jaccard、（§5.3）logistic 纯图模型。
- **指标**：AP、ROC-AUC、precision@k（k=正例数）、lift@1%、Brier。
- **防泄漏**：所有特征只用 ≤T 信息；标注只用任务文本（O*NET 陈述，早于样本期）；
  agent 从不输出职业名称。

## 5. 结果

### 5.1 三守则的签名证据（不需要 LLM 的部分，2016–2026）

**(a) 互补性再捆绑：✓ 存在且在生成式 AI 冲击后加速**

| 年 | 新 bundle 数 | 平均任务数 | bundle 内 E 方差 | 高低暴露混合占比(E0×E2) |
|---|---|---|---|---|
| 2017 | 14,205 | 4.90 | 0.463 | 0.575 |
| 2020 | 6,924 | 5.35 | 0.458 | 0.573 |
| 2022 | 7,792 | 5.98 | 0.503 | 0.642 |
| 2025 | 11,946 | 6.26 | 0.500 | 0.658 |

新岗位越来越宽、内部分化越来越大、越来越"混着"高暴露与语境嵌入任务。（`signature_trend.csv`）

**(b) 层级解绑：✗ 未见收窄（该行业、该窗口）**

企业—年面板（3,790 个企业—年）：平均岗位任务数 2.83→5.78、企业任务全集/岗位 2.54→5.28、
岗位内 E 方差 0.243→0.456，**全部上升**；拆岗事件 35–230 起/年、无趋势。
→ Garicano 的跨度收窄被 (a) 的互补补强盖过。（`firm_year_stats.csv`、`split_events.csv`）

**(c) 模仿性模板扩散：✓ 约 1/3 新岗位是既有模板的产物**

结构相似 ≥0.8（近原样）企业内 1.3–4.0%、跨企业 0.5–1.2%；
0.4–0.8（改良复制）稳定 ~33%；表面相似度残差>0 的比例由 0.41(2017) 升至 0.58(2021+)。
（`rule_c_trend.csv`、`rule_c_adoption.parquet`）

### 5.2 逐对回测（T=2019→2020，全量 3,599,363 对，46,485 正例）

| 分数 | AP | AUC | P@k | lift@1% |
|---|---|---|---|---|
| 共邻（最强单一基线） | 0.1081 | 0.7912 | 0.1832 | 15.65 |
| 优先连接 | 0.0887 | 0.8112 | 0.1571 | 13.34 |
| jaccard | 0.0238 | 0.6213 | 0.0376 | 3.01 |
| 持续性 | 0.0454 | 0.5951 | 0.1439 | 11.03 |
| B4 模块×同暴露×凝聚 · **LLM** | 0.0199 | **0.5374** | **0.0543** | 4.61 |
| B4 · 词表 | 0.0157 | 0.5176 | 0.0316 | 2.76 |
| B1 模块×同质×可编码×凝聚 · **LLM** | 0.0166 | **0.5309** | **0.0375** | 3.09 |
| B1 · 词表 | 0.0136 | 0.5075 | 0.0165 | 1.38 |
| A 互补再捆绑（最优变体）· LLM | 0.0125 | 0.4855 | 0.0132 | 1.07 |
| A · 词表 | 0.0128 | 0.4947 | 0.0141 | 1.04 |

**读法**：同一候选子集上，(b) 用 LLM 判定后 AUC 0.5075→0.5309/0.5176→0.5374，
P@k **翻倍到 2.3 倍**（0.0165→0.0375；0.0316→0.0543）→ LLM 的模块/层级判断带来可用结构信号；
(a) 无论 LLM 还是词表都无信号（AUC<0.5，即该规则在"任务对"层面几乎不成立）。

### 5.3 三方对撞（logistic：2018 训 → 2019 测，全量同子集）

| 模型 | AP | AUC | Brier | lift@1% |
|---|---|---|---|---|
| 纯图+持续（零模型） | 0.12482 | 0.8267 | 0.012239 | 17.10 |
| **+ 词表语义（安慰剂对照）** | 0.12441 | 0.8271 | 0.012236 | 17.08 |
| **+ LLM 三守则语义** | **0.12926** | **0.8354** | **0.012211** | **17.52** |

**这是本次最重要的结果**：词表版与零模型无差别（安慰剂通过，AP 甚至略低），
LLM 版四项指标同时改善（AUC +0.0087、AP +0.0044、Brier −0.000028、lift +0.42）。
增量来自 LLM 判定本身，而非"随便加点语义特征"。

### 5.4 逐特征消融：增量由谁承载（关键诊断）

2018 训 → 2019 测，逐个加入语义特征：

| 加入的特征 | AP | AUC | Brier | lift@1% |
|---|---|---|---|---|
| 纯图基线 | 0.12482 | 0.8267 | 0.012239 | 17.10 |
| + E_gap_norm（暴露差距，(a) 的核心） | 0.12490 | 0.8275 | 0.012238 | 17.10 |
| + ctx_low（语境嵌入，(a) 的另一半） | 0.12451 | **0.8257** | 0.012238 | 17.08 |
| + same_mod（同功能模块，(b) 的核心） | **0.12899** | **0.8350** | **0.012208** | **17.49** |
| + cod_geom（可编码性） | 0.12449 | 0.8264 | 0.012239 | 17.07 |
| + 全部语义 | 0.12926 | 0.8354 | 0.012211 | 17.52 |

对照（词表属性，同子集）：+ same_mod 仅 0.8282→0.8293（+0.0011），全部语义 0.8302。

**结论**：增量**几乎全部由 `same_mod` 承载**（+0.0083），而 LLM 的功能模块标签显著优于 O*NET SOC 派生的模块
（+0.0083 vs +0.0011）；`E_gap`、`ctx_low`、`cod_geom` 三项接近零甚至为负。
即：当前 LLM 的贡献是**更好的功能语义分类**（测量层），尚不是 (a)/(b) 的机制本身。

### 5.5 agent 盲判试点（n=48，未看真值）

我以三准则宪法盲判 48 对：AUC **0.888**、top-5 命中 3/5；对照共邻 0.847（1/5）、
优先连接 0.814、持续性 0.758、词表 A 0.209 / 词表 B 0.400。
观察：实现的 5 个新共捆绑**全部**被我判为 B（同模块均质）；我给的 7 个 A 判定无一实现；
**C 未被指派**——模仿性无法从任务对语义识别，必须依赖企业/模板语境（与 (c) 的表面残差设计一致）。
（`pair_judge_llm.json`、`pair_judge_truth.parquet`）

## 6. 校准发现（副产品，但重要）

LLM `codability`（可否被机器替代）与 GPT-4 `E`（暴露度）系统性分歧：

| | codability=0 | =1 | =2 |
|---|---|---|---|
| E0 | 45.2% | 51.9% | 2.9% |
| E1 | 6.1% | 60.6% | 33.3% |
| **E2** | **24.4%** | 68.0% | **7.6%** |

E2 中有近四分之一被判为"高度依赖现场/关系/责任"、仅 7.6% 明判纯可编码。
**"LLM 能影响"≠"机器能替代"**——支撑提案把暴露度当冲击压强、把语境嵌入当存留/再捆绑条件的两分设计。

## 7. 结论与边界

1. **(b) 是本轮唯一通过检验的准则**：LLM 的模块/层级判断在逐对预测上有真实增量（P@k 翻倍）。
2. **(a) 在"任务对"层面不成立，但在"岗位构成"层面成立**：新岗位的暴露混合度确实上升，
   但新增任务对的绝大多数仍是**同模块**的（B 形态）。解释：高×低暴露的混合发生在
   *模块内部*（同一模块既含可编码任务也含语境任务），因此 E 差距是模块属性而非"新对"的属性，
   逐对预测里用 E 差距没有杠杆，用模块才有。
   → **改法**：(a) 应改写为**岗位层面的混合度预测**（在给定模块下预测新岗位的 E 方差/混合份额），
   而不是任务对层面的链接预测。
3. **(c) 必须在企业/模板层识别**，任务对语义无法识别模仿（§5.4 已证）。
4. **行业特异性**：(b) 的缺席可能是新材料行业特征（工艺/现场密集，互补性强）；
   需在其它行业样本上重跑才能判断是理论问题还是情境问题。
5. **覆盖局限**：LLM 标注覆盖 84.1% 任务、71% 候选对；缺失为随机（批内打乱），
   子图内比较有效，但全量数字待补（剩余 19 批）。
